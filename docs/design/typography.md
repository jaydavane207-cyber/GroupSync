# Typography System

GroupSync utilizes the `Inter` font family for modern legibility.

- Body: `-apple-system, BlinkMacSystemFont, "Inter", "Segoe UI", Roboto`
- Headings: Letter spacing `-0.02em` with font weights 600 (Semibold) and 700 (Bold).
- Monospace: Courier New, monospace for timestamps and scores.
