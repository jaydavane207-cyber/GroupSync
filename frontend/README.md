# GroupSync Frontend Application

A React 19 application bundled with Vite 7 and styled using Tailwind CSS, Framer Motion, and Lucide React.

## Directory Structure

- `src/pages/`: Route-level views
- `src/components/`: Modular component library categorized by functionality
- `src/hooks/`: Custom stateful hooks
- `src/context/`: Global and contextual state providers
- `src/lib/`: Services, Supabase client, storage, and utility helpers
- `src/state/`: Zustand state management stores
- `src/styles/`: Modular CSS tokens and stylesheets
- `src/constants/`: Routing, API endpoints, role and skill definitions
- `src/types/`: TypeScript interfaces and definitions
- `tests/`: Unit, integration, and e2e test specifications

## Commands

- `npm run dev`: Launch local Vite dev server
- `npm run build`: Compile production bundle
- `npm run lint`: Run ESLint checks
- `npm run preview`: Preview production build
